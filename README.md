# XYANI876 Collection

Official e-commerce storefront for XYANI876 Collection — **Complete the Look**.

Built for mobile-first shopping in Jamaica with product availability, cart, checkout, Cash on Delivery, online-payment workflow, Knutsford Express delivery, and a browser-based store admin dashboard.

## Store management
Open `admin.html` to manage products, inventory and orders. This GitHub Pages edition stores admin changes and orders in the current browser using localStorage. For production multi-device inventory, secure admin login, automatic card processing and shared order storage, connect a hosted backend/payment gateway.

## Deployment
Publish the repository root with GitHub Pages (branch `main`, folder `/root`).
